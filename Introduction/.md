# ✅ Interview Answer (2–5 Minutes)

My latest project was an AI Customer Support Platform that enables users to interact with company knowledge using natural language.

Users upload manuals, FAQs, warranty documents, and support guides.

Instead of relying only on the LLM's knowledge, we implemented a Retrieval-Augmented Generation (RAG) pipeline.

When a user submits a question:

1. Authenticate the user.
2. Retrieve conversation history.
3. Generate an embedding for the query.
4. Search the vector database.
5. Retrieve the most relevant document chunks.
6. Build the final prompt.
7. Send the request to Azure OpenAI.
8. Validate the output.
9. Stream the response back to the user.

My responsibilities included backend architecture, FastAPI development, RAG implementation, Azure OpenAI integration, authentication, deployment, monitoring, and performance optimization.

# 🚀 Redis Caching

Frequently asked questions should not trigger repeated LLM requests.

Without cache:

100 Users

↓

100 LLM Calls

With cache:

100 Users

↓

1 LLM Call

↓

99 Cached Responses

Benefits:

- Lower latency
- Reduced cost
- Better scalability
