For your FastAPI + LangGraph + RAG applications, I'd recommend:
- VS Code Python Debugger (debugpy) for stepping through code.
- Python logging with JSON-formatted structured logs for application events.
- pytest + pytest-mock for unit tests and dependency mocking.
- OpenTelemetry for tracing agent execution, database calls and LLM requests.

# Rule

- F9: Breakpoint lagana/hatana
- F5: Next breakpoint tak jaana
- F10: Step Over
- F11: Step Into
- Shift + F11: Step Out
