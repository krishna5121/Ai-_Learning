connect()      → Database se connection establish karta hai.

cursor()       → SQL execute karne ke liye Cursor object deta hai.

execute()      → SQL database ko bhejta hai.

fetchone()     → Ek row return karta hai.

fetchall()     → Saari rows return karta hai.

commit()       → Changes permanently save karta hai.

rollback()     → Uncommitted changes undo karta hai.

close()        → Connection ya Cursor band karta hai.
